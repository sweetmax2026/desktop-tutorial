# pangpang（macOS）

一个常驻菜单栏的轻量专注工具。pangpang 是可拖动的悬浮入口：点击她打开工具箱，再由她陪你完成番茄钟、冥想和情绪记录。

## 使用

在终端进入此目录后运行：

```zsh
zsh scripts/build-app.sh
open build/pangpang.app
```

首次运行 macOS 可能询问是否打开未签名的本地应用；选择“打开”即可。`build/` 是每次构建生成的可运行应用，不需要 Xcode 工程。

## 目前功能

- 圆形 pangpang 悬浮按钮，可拖动；换屏后会自动落回可见区域，避免被裁切。
- 点击按钮打开工具箱；右键可直接开始专注、隐藏桌面入口或退出。
- 25 分钟专注 → 自动 5 分钟休息；每完成 4 轮专注 → 自动 10 分钟长休息。
- 休息结束**不会**自动开始下一轮；点击 pangpang、气泡“开始下一轮”或菜单栏同名菜单项，都能一键继续。
- 工具箱首页提供快捷开始、以及播放器式的暂停／继续控制；专注/休息的倒计时不会一直占用桌面。
- 支持 1 分钟冥想：默认每日 11:00、16:30、20:00 提醒，也可增删时间。
- 支持本地情绪记录：选择情绪并附加 100 字以内文字，文字也可独立保存为“随手记”。
- 支持“数据详情”：按今天、近 7 天、近 30 天或自定义日期查看趋势与每日明细。
- 到点会显示 pangpang 气泡，并发送 macOS 通知（首次启动请允许通知）。
- 关闭工具箱或隐藏悬浮入口后，番茄钟继续；进程退出后再打开也会恢复尚未结束的计时状态。

## 菜单栏

菜单栏的爪印图标始终保留，可以显示被隐藏的 pangpang、暂停或结束当前计时，以及退出应用。应用没有 Dock 图标，这是预期行为。

数据只存放在本机；项目不包含聊天模型、云同步、用户状态、构建产物或签名信息。
