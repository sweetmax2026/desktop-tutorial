# Pang 大师｜猫咪陪伴番茄钟（macOS）

正式名称是「Pang 大师」，品牌字样显示为「Pāng 大师」，Pang 读一声。原名为 pangpang / Pangpang Focus Companion。产品介绍使用「猫咪陪伴番茄钟」，便于首次了解用途；尚未配置应用商店搜索词或公开发行。

一个常驻菜单栏的轻量专注工具。默认隐藏桌面圆形入口，通过菜单栏或全局快捷键 Control + Option + P 打开／收起专注主页面，陪你完成番茄钟、冥想、情绪记录和 App 管控。

首页点击“添加本轮任务／编辑”统一设置任务名称、时长与类别；名称右侧下拉可选择或删除历史任务，保存新任务后会加入列表。删除历史选项不删除已完成的专注记录。计时数字只显示当前时长。

## v1 起点

当前版本为 v1.2.3（build 37）。准备页采用窗边小猫背景和窄体计时数字，顶部显示 Pāng 大师。任务入口统一编辑名称、时长和类别，支持历史任务选择与删除。点击开始立即计时，同一组窄体数字在0.35秒内从左侧移到中央，字色和蓝云背景渐变；恢复已有计时直接显示运行页。冥想和记录心情入口默认无底色，hover 时显示淡白按钮面和柔和阴影。

准备、专注、完成和休息仍在同一窗口展示。专注中仅有倒计时和长按放弃，不支持暂停。默认手动开始休息和下一轮；设置里的两个自动开关各自独立生效，长休息按当天完成轮数计算。已有计时和记录不迁移或清空。

v1.0.3 的主页面只从右上角设置进入专注守护。设置旁的守护状态仅作提示，不跳转；冥想和情绪记录作为两个独立入口居中展示。

v1.0.2 的设置使用窄侧栏，分为计时与显示、专注守护。主页面的 App 管控入口直达专注守护，时长和显示设置点击保存后生效，App 管控开关和列表调整立即生效。窗口尺寸不随页面切换自动变化。

v1.0.0 将专注、专注主页面、设置、数据统计、情绪记录、一分钟冥想和 App 管控统一为浅蓝色原生窗口。功能页面原位切换，窗口位置和大小不变。v0 的提交历史保留，已有本地记录、提醒、时长设置和黑名单继续使用。

源码包含猫头图标、情绪表情、猫爪素材和原生图标文档，构建不需要下载图片。v1.0.5 将守护、冥想与休息结束提示统一为浅蓝卡片，今日收获使用无描边蓝色小猫爪，继续复用现有探爪小猫。系统通知的外围样式由 macOS 控制。详细变更见 CHANGELOG.md。

## 使用

在终端进入此目录后运行：

```zsh
zsh scripts/build-app.sh
open "build/Pang 大师.app"
```

需要安装可用的 Xcode 工具链，包含 Swift 编译器、actool 和 Icon Composer 支持。构建脚本使用本地签名，生成的 App 不是经过苹果公证的发行安装包。项目也保留可在 Xcode 中打开的工程。build/ 是每次构建生成的可运行应用。

## 目前功能

- 专注主页面和专注页使用统一的浅蓝色横向窗口，蓝紫色主按钮，底部集中展示今日猫爪收获。冥想、情绪记录使用绿、粉色直接入口；App 管控位于设置内的专注守护，不重复排列快捷入口和功能列表。
- 准备页从任务入口设置时长、类别与选填任务；点击开始直接进入安静计时。
- 专注主页面与专注页的右上角共用设置：专注时长、短休息、长休息、长休息间隔、圆形悬浮入口和悬浮计时卡开关。默认 25 / 5 / 10 分钟、每 4 轮长休息；设置只用于之后开始的阶段，当前倒计时和有效时长不变，退出再打开也保留。
- 设置在进入前的同一个窗口内原位显示，尺寸不变；保存并返回会应用设置并回到原页面，左上返回不保存草稿。恢复默认只修改草稿，点击保存后才生效。
- 数据统计在原窗口显示，默认今天，支持近 7 天、近 30 天、自定义范围。上方展示有效专注分钟和完成轮数，下方展示趋势及可展开笔记的记录；可切换冥想和情绪。专注时长含提前结束的有效时间，轮数仅计完成；图表按结束时间归类，不推算暂停所在的具体时段。
- 可拖动的小专注卡片：长期「自动显示」开关会被记住，关闭后每次开始均不会出现；卡片上的关闭只收起当前一轮，菜单栏可临时找回。
- 今日收获收在底部：完成轮次显示蓝色猫爪，提前结束显示灰色猫爪；点击可查看记录。完成页有一次轻弹动效，支持系统减少动态效果设置，等待选择期间不自动计时。
- 专注时间轴和类别时长：完成与提前结束均记录有效时长，暂停不计入；旧记录保留并标注时间段为估算。
- 菜单栏显示专注、休息、暂停或冥想状态，不显示倒计时；全局快捷键 Control + Option + P 打开／收起上次停留的工具页。
- 默认隐藏圆形悬浮入口；菜单栏「显示悬浮圆形入口」可切换，选择会被保存。开启后可拖动，换屏自动落回可见区域。
- 点击按钮打开专注主页面；右键可直接开始专注、隐藏桌面入口或退出。
- 默认 25 分钟专注，完成后手动选择开始 5 分钟休息；按当天完成轮数，每 4 轮安排 10 分钟长休息，每天重新累计。跨午夜的一轮计入完成当天，不改变已开始的倒计时。可在设置内调整。
- 设置 → 计时与显示提供独立的“自动开始休息”和“自动开始下一轮”开关，默认都关闭；保存后从下一次阶段结束生效，不改变当前倒计时。默认仍手动开始休息和下一轮；两项都开启时自动循环，沿用当前任务及长休息轮数。手动结束休息或放弃专注会停止循环，重开应用不补算离线多轮。
- 新专注不提供暂停。按住「放弃专注」1.5 秒结束，提前松开或移出取消；键盘和辅助功能提供确认。实际时间保留，但不计完成轮次。旧版暂停状态保留一次继续或手动重置入口，不自动清空。
- 休息页可结束休息，回到准备状态而不启动下一轮；重置不会删除历史。没有跨天自动重置。
- 一分钟冥想在原窗口展示浅蓝呼吸动画和“吸气／呼气”提示，支持重新开始；默认每日 11:00、16:30、20:00 提醒，可在页内增删时间。完成后不弹出需要确认的窗口。
- 情绪记录横排展示五种感受，支持 100 字以内文字和文字单独保存。中文输入使用原生文本编辑器，输入法组合期间不截断文字，提交后检查上限。
- 情绪和冥想的查看记录入口直接显示各自统计，返回原页面。
- App 管控支持通过原生选择器添加多个 App、移除和空列表提示。仅在专注计时中隐藏黑名单 App，监听激活、取消隐藏和启动事件，并每 0.4 秒复核；核实隐藏状态后才显示成功，失败会重试并提示。休息、完成、暂停、关闭管控或移除应用后停止拦截。这是可恢复的隐藏与切回机制，不是系统级禁止启动；不会强制退出、读取聊天或删除数据。
- 到点会显示 Pang 大师提示卡，并发送 macOS 通知（首次启动请允许通知）。完成专注的提示卡不抢输入焦点，点击查看收获才打开完成页；所有轻提示卡统一在 10 秒后收起，也可手动关闭。重启后补发尚未展示的完成提示，同一条记录不重复弹出。系统通知可能受共享屏幕、锁屏或专注模式影响，提交成功不代表已显示横幅。
- 关闭专注主页面或隐藏悬浮入口后，番茄钟继续；进程退出后再打开也会恢复尚未结束的计时状态。

## 菜单栏

菜单栏始终显示简化单色猫头，并在旁边显示当前状态。可打开专注主页面、显示悬浮入口、结束休息、开关 App 管控，以及退出应用。专注时的「放弃本轮」打开计时页，由长按防误触。Dock 和系统通知共用浅蓝底彩色猫头图标；关闭页面不会退出应用。

数据只存放在本机；项目不包含聊天模型、云同步、用户状态、构建产物或签名信息。

- v1.0.1 支持拖动主窗口边框调整大小，最小 800 × 600；页面切换保持窗口尺寸。圆形悬浮入口与悬浮计时卡分别控制，设置页与菜单栏同步。
- v1.1.1 普通专注窗口保持打开，点击另一块屏幕或其他应用不会自动收起；到点提醒也不会主动隐藏它。关闭按钮、快捷键和菜单的主动收起仍保留。

## 界面配图与验证

应用实际使用的配图和图标源文件位于 Resources/ 与 Assets.xcassets/。design/screenshots/ 保存经过筛选的独立预览截图，仅含示例数据，不代表用户真实记录。

```zsh
zsh scripts/check-focus-flow.sh
```

此检查运行计时、App 管控与统计回归测试，并生成使用独立数据的 build/PangpangFlowPreview.app。需要完整 Xcode 工具链；它不会安装或覆盖正式应用。版本验证范围见 RELEASE-CHECKS.md。

统计侧栏改版的独立原生预览：运行 `zsh scripts/preview-statistics.sh`，再打开 `build/Pang Statistics Preview.app`。窗口使用示例记录，支持日期筛选、三类统计切换、成果展开与滚动；预览菜单可切换800×600、1100×760和空专注记录。设计对照见 `design/statistics-sidebar-2026-10-31/design-qa.md`。
