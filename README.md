## Pangpang Codex Desktop Pet

pangpang is a cool white cat with golden eyes and a pink nose, made as a custom Codex desktop pet.

## Included behavior

- Calm idle and brief click / hover acknowledgement
- Left and right movement while dragging
- Focused task, waiting, review, and failure states
- 16-direction gaze tracking

## Install

Copy `PangpangCodexDesktopPet/` to `~/.codex/pets/pangpang/`, then fully quit and reopen Codex. Select **pangpang** in the Pets settings.

## Package format

The package uses the Codex v2 spritesheet format: 1536 x 2288 pixels, 8 x 11 cells, 192 x 208 pixels per cell, with `spriteVersionNumber: 2`.

Only the installable package is tracked here. Source photos, generation work files, and local validation artifacts are intentionally excluded.
